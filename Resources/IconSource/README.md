# Folded F identity

The icon combines FileMint's F with the folded corner of a fresh sheet of paper.
A porcelain tile and mint material form the Dock/app icon; a separately fitted
monochrome F serves the menu bar and Finder toolbar at 18 points.

`FileMint-Concept.png` is the ImageGen concept reference. The production icons
are drawn from AppKit vector geometry in
[`scripts/generate_app_icon.swift`](../../scripts/generate_app_icon.swift).
Run `make icon` to regenerate them.

See the [original concept prompt](https://github.com/FileMintApp/FileMint/blob/46882c07d1eee100cb6c200a89e72201c78a36c8/Resources/IconSource/BRIEF.md)
for design history and the [appearance contract](../../specs/domains/presentation.md#appearance)
for current Finder artwork rules.
