# 快捷指令与启动器

[English guide](SHORTCUTS_AND_LAUNCHERS.md)

本指南对应**尚未发布的联动开发版**。外部入口只打开待确认草稿，只有点击
**创建**才写入文件；快捷指令返回“草稿已打开”不代表文件已保存。

FileMint 整体仍支持 Apple 芯片 Mac 和 macOS 13.0 及以上。只有“快捷指令与
启动器”需要 macOS 13.3 及以上和已登录的可交互桌面；在 13.0–13.2 上，其设置
入口置灰并说明原因，直接外部草稿/搜索调用也会被拒绝，原有文件创建和快捷搜索
仍可使用。当前原生证据来自 macOS 27.2、快捷指令 10.0 和 Raycast 2.10.1.0；
macOS 13.0/13.3 实机尚未验证。Raycast 需另行安装。具体构建、缺少的环境和首次使用者验收见
[任务记录](tasks/2026-10-29-shortcuts-and-launchers.md)。

## 新建项目笔记

固定工作目录先在**设置 → Finder 与文件夹**中授权。那里会保存目录权限，同时
调整 Finder 菜单范围。只为一次草稿选择的目录不会自动加入监控列表。

进入**设置 → 快捷指令与启动器 → 新建项目笔记**：

1. 使用快捷指令：打开快捷指令 App，新建工作流，添加 FileMint 的**打开文件
   草稿**动作。选择启用的 Markdown 等文本模板及固定保存位置；文件名设为
   **每次均询问**，初始内容保留**模板内容**。
2. 使用 Raycast：点击 **Raycast…**，配置模板和位置，文件名保留**在 Raycast
   运行时填写**，将脚本导出到自己选择的目录。在 Raycast 设置 → Extensions →
   Script Commands 中添加该目录。
3. 日常运行时只填笔记名称。在草稿中核对名称、精确模板、位置和正文，再点击
   创建；取消不产生文件。

生成器中的**预览草稿**使用同一个创建面板。取消预览或完成创建后会恢复原配置；
草稿修改不会反向改写命令配置。目录选择取消或写入失败时，草稿继续保留。

## 保存工作流生成的文本

在“打开文件草稿”前放一个**文本**动作，或其他能够输出文本的动作。配置文件名、
文本模板和位置，将初始内容设为**指定文本**，在“文本”字段连接上一步的文本
输出。运行时无需再次手动输入名称或正文。

空格、换行、中文、emoji 和 `{{year}}` 等字面量会原样保存，正文里的 URL 或
Shell 语法不会执行。需要空白文件时选择**空内容**。Office 模板不接受外部正文，
空字符串也不例外；选择**模板内容**则沿用模板的正常渲染规则。

## 显示快捷搜索

在快捷指令中添加**显示快捷搜索**，无需参数。也可以在设置页的对应场景中生成
Raycast 命令或复制链接。重复调用会聚焦已有搜索并保留查询，不会把搜索切换关闭，
这个动作本身不创建文件。

## 导出、本机测试与分享

页面只报告已观察到的状态：脚本已保存、链接已复制、FileMint 已收到本次本机
测试请求。第三方是否导入成功，需要在相应工具中实际运行。接入指南保持非模态，
不会挡住真实调用；**返回编辑**保留本次配置，关闭设置则释放配置。

Raycast 脚本不依赖 Node/Python，运行参数按数据编码。脚本成功退出只表示 macOS
接受了 URL 交付，不是草稿接收或文件创建收据。

导出文件和链接可能包含正文、目录路径及本机模板/收藏 ID，分享前请检查。第三方
工具可能保留自己的历史，较长或敏感正文优先使用原生参数。FileMint 不上传配置，
不监听剪贴板，也不持久保存正文预设。

## 通用 URL v1

```text
filemint://draft?v=1&name=Project%20Note&template=markdown
filemint://draft?v=1&name=Workflow&template=markdown&text=First%20line%0ASecond%20line%0A
filemint://draft?v=1&name=Empty&template=markdown&text=&location=ask
filemint://search?v=1
```

每个参数值分别编码，例如 `A & B + # %` 编为
`A%20%26%20B%20%2B%20%23%20%25`。`+` 按字面加号处理。

| 字段 | 含义 |
| --- | --- |
| `v` | 必填，必须为 `1`。 |
| `name` | 可选文件名；仅填名称时补上模板后缀，明确提供的后缀必须匹配模板。 |
| `template` | 本机启用模板的精确 ID；明确指定但不存在或停用的 ID 会被拒绝。 |
| `text` | 缺省使用模板内容；明确提供时原样保存，空值表示空内容。 |
| `directory` | 可选绝对本地目录建议，不附带访问权限。 |
| `favorite` | 可选本机常用目录 UUID，ID 本身不授予权限。 |
| `location` | 仅接受 `ask`，在 FileMint 中选择位置。 |
| `id` | 可选 UUID，仅用于内存中的请求去重。 |

`directory`、`favorite` 和 `location=ask` 互斥。搜索只接受 `v=1`。未知/重复字段、
URL 路径、片段、端口、用户信息、错误 UTF-8/百分号编码及 NUL 都会在 FileMint
收到的表示上被校验；上游或 macOS 已做的 URL 规范化无法还原成调用者最初写法。

按 UTF-8 字节计，完整 URL 限 16 KiB、URL 正文 8 KiB、原生正文 1 MiB、文件名
1 KiB、目录 4 KiB、模板/收藏 ID 256 字节。超限拒绝，不截断。更长正文使用原生
快捷指令；跨 Mac 分享时需重新配置本机 ID 和路径。

相同 ID 与相同规范化请求会聚焦其活动草稿；同 ID 改参数会冲突。已结束的 ID
十分钟内不能重开。去重记录不落盘，容量有限，较旧记录可能被淘汰；普通的新调用
无需提供 ID。已有草稿的输入和撤销保留；忙碌或模态期间的请求直接拒绝，不排队。

## 无法打开时

先完成或取消未完成草稿，再重试新请求。忙碌时先处理当前模态或文件操作。模板
不可用时重新选择已启用模板；位置失效时明确重新授权。FileMint 保留输入，不会
自行换到其他目录。

准备阶段未能在限定时间内就绪时，快捷指令返回不可用；取消准备后不会延迟弹窗。
本功能面向交互式确认草稿，不用于无人值守的后台批量创建。

主 App、Finder 扩展和 appcast 保持最低 macOS 13.0；Homebrew 保留 Ventura
要求，不再额外限制为 13.3。功能可用性由 FileMint 内部判断，不限制应用更新。
本指南不代表已发布新版、推送 Homebrew tap 或上线网站。
