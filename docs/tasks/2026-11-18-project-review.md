## 实现决定

- Finder 传递点击时的对象身份。跨卷移动在源卷废纸篓中保留原件，以便保存复制结束后仍通过打开的文件描述符写入的数据。不可回收或无法确认所有权时保全现有对象。
- 创建采用绑定目的目录的暂存写入与独占发布。Office 导入若在记录文件身份前中断，保留无法确认归属的私有暂存数据，允许重新导入。
- 设置导入按最初发布版本的备份结构识别，继续支持旧版 plist 包装。快速搜索只在草稿实际接手后清除状态。
- 发布提升前用远端临时 Git 引用协调不同候选，在本地发布日志中记录持有方并核对最新稳定版本。网站为每次 main 推送构建，对发布相关内容按提交的发行说明版本延迟部署。
