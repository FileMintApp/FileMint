# Task: 文件信息与 MD5 / SHA-1 / SHA-256 / SHA-512 校验

Status: planned
Next action: 评审本轮修订的算法选择弹窗；本任务继续停在规划阶段，尚不实施产品代码。

## Objective and scope

- 需求一：在 Finder 右键选中资源后，从「文件（夹）工具 → 文件信息…」快速查看基本信息，在弹窗内选择 MD5、SHA-1、SHA-256、SHA-512 或全部，再主动计算校验值。
- 本任务独立实施、验收；不依赖[密码加密保护任务](2026-10-19-file-encryption-protection.md)，也不在信息窗口加入加密或解密操作。
- 首版：单个普通文件的基本信息和四种校验值；单个普通文件夹只展示自身元数据，明确说明不计算目录校验值、总大小或子项数量。包、符号链接、Finder 替身及特殊设备不读取内容，不自动跟随目标；展示不支持说明。
- 多选批量计算、目录摘要规范、包内递归、校验清单导入导出、后台监听、持久化摘要缓存不纳入首版。单选是本方案的首版取舍，不是 Apple 限制。
- 独立子开关默认关闭，旧配置缺失／损坏值也关闭；默认位于子菜单，可按既有规则设置一级菜单。模块关闭保留子项选择。新建文件、资源工具原有行为不变。
- 本轮只新增 task 和路线图入口，不把未来行为写成已上线功能；实施前更新所属 SPEC。

## Apple 官方能力与约束

查阅日期：2026-10-19。以下区分官方事实和本任务设计；文档/API 存在不等于已通过 FileMint 沙盒或安装态验收。

| 主题 | 官方依据 | 方案结论 |
| --- | --- | --- |
| 四种算法 | [HashFunction](https://developer.apple.com/documentation/cryptokit/hashfunction) 列出 `Insecure.MD5`、`Insecure.SHA1`、`SHA256`、`SHA512`；支持 `update(data:)` / `finalize()` | 直接用系统 CryptoKit，同一分块输入本次所选算法实例（选全部时四个）；无需第三方依赖或 shell 命令 |
| 大文件 | [Insecure.MD5](https://developer.apple.com/documentation/cryptokit/insecure/md5) 明确支持分块迭代处理不能整体放进内存的数据 | 固定内存缓冲、后台读取；不能把整文件载入 `Data`，不能承诺任意大小“瞬间完成” |
| 算法安全性 | [Insecure](https://developer.apple.com/documentation/cryptokit/insecure) 将 MD5 / SHA-1 定义为兼容旧服务的不安全算法 | 保留用户要求的四项，附短说明“MD5 / SHA-1 仅用于兼容性校验，建议使用 SHA-256”；不把摘要比对称为可信来源认证 |
| 文件权限 | [Accessing files from the macOS App Sandbox](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox) 描述用户选择、书签及其他访问控制限制 | 右键选中不是主 App 获得读取权的充分条件；复用有效授权，必要时精确请求只读访问 |
| 文件并发访问 | [NSFileCoordinator](https://developer.apple.com/documentation/foundation/nsfilecoordinator) 协调参与者的读写，每个实例限同一线程使用 | 在工作线程协调读取并检查文件身份／版本；不能据此声称阻止所有外部进程修改 |
| Finder 入口 | [Finder Sync](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Finder.html) 允许监控目录内的上下文菜单，但声明其并非通用 Finder UI 修改工具 | 复用已有菜单能力；不承诺所有 Finder 场景都回调，也不将此解释为 Apple 对通用工具用途的认可 |

所查公开文档没有提供“向 Finder 显示简介窗口插入四种摘要”的扩展接口，也没有现成四摘要结果面板。因此使用 FileMint 自有原生面板，不修改 Finder 系统窗口、不用私有 API 或 AppleScript 注入。若 Finder 未回调，不能以扩大授权或监听全盘作为修复；主 App 手动选取入口可另立后续需求。

## Decisions and progress

### 交互方案（2026-10-19 按用户意见修订）

入口为「文件（夹）工具」子菜单中的「文件信息…」，点击直接打开 FileMint 原生弹窗，不在 Finder 菜单继续展开四种算法。这里将用户所说的“文件信息子菜单”落实为可点击的子菜单项：真正带展开箭头的 `NSMenu` 容器通常用于展开下一层，不能同时承担打开弹窗的主动作。

1. 设置 → 扩展 → 文件（夹）工具增加「文件信息」行，说明“查看信息并计算文件校验值”，沿用现有开关和菜单位置控件。
2. Finder 单选资源后显示「文件信息… / File Info…」。只使用菜单生成时捕获的单选；背景、工具栏、侧栏、多选没有入口。菜单阶段不读取内容或做耗时属性查询。
3. 点击只打开原生信息弹窗并读取必要元数据，不自动计算。先展示图标、文件名、类型、逻辑大小、位置、创建及修改时间；未知属性显示“不可用”。路径可展开、选择或主动拷贝，长路径不挤压主操作区。
4. 弹窗提供带持久标签“校验算法”的原生单选下拉控件，默认 `SHA-256 · 推荐`，另有 `SHA-512`、`SHA-1 · 兼容旧系统`、`MD5 · 兼容旧系统` 和 `全部四种算法`。既可按需输出一种，也保留一次计算四种的能力。每次新打开默认 SHA-256，不将一次选择不安全算法变成永久默认。
5. 用户点击主按钮“计算校验值”才读取内容。没有选择变化即自动重算的行为。计算时固定算法选择，显示字节进度与“取消”；停止后才能改选。计算完成后主按钮变为“重新计算”，结果旁出现“拷贝结果”。
6. 切换算法立即更新下面的小提示，并把旧结果退出当前有效结果区、禁用拷贝，显示“尚未计算”；不会把旧算法值挂在新算法名称下。选择“全部”时依次显示 MD5、SHA-1、SHA-256、SHA-512，保留逐项拷贝与“拷贝全部”。
7. “比对校验值”默认折叠；用户主动输入／粘贴，按当前单选算法校验长度和字符，只去除首尾空白、接受大小写十六进制。全部模式下需先选择一个算法进行比对。用文字和图标表示一致／不一致，不只靠颜色，无剪贴板轮询。
8. 文件夹显示“校验值仅适用于普通文件；此处不扫描文件夹内容”，算法和计算区禁用并解释原因，不用目录 inode 大小冒充内容总大小。
9. 关闭窗口或 Esc 取消当前计算；释放句柄和授权，部分摘要不能显示为完成。Cmd-W 关闭；Return 仅在非多行输入焦点且计算可用时执行主动作；Tab 顺序跟随布局。完成结果仅保留于当前窗口。

### 视觉与布局要求

- 原生独立可调整大小的信息面板，建议初始 600 × 560 pt、最小 520 × 480 pt；以屏幕可用区域为上限。全部结果／比对展开时内容可滚动，底部操作区始终可达，不为 128 位十六进制字符缩小字体。
- 遵循 FileMint 现有瓷白／石墨中性色与低饱和薄荷强调色，使用系统字体、原生图标和自适应颜色。高级感来自准确对齐、留白和清晰层级，不依赖大面积渐变、强毛玻璃或装饰卡片。
- 单列布局：紧凑文件摘要 → 算法选择及说明 → 校验结果 → 可折叠比对。内容边距 24–28 pt，相关控件间距 8–12 pt，分区间距 20–24 pt；标题、次级元数据、等宽摘要有明确层次。
- 校验值为独立可选择的等宽文本区；SHA-512 完整换行，拷贝获得连续值。未计算时显示简短空状态，计算中显示实际进度，完成显示结果，失败显示可操作原因；不使用伪进度。
- 只设一个主按钮。完成前禁用拷贝；重新选择或重算立刻使旧结果失效。键盘焦点可见；非色彩提示、VoiceOver 标签、动态文字长度、明暗外观和降低透明度都必须验收。
- 本轮对话中的交互预览采用 `example.txt` / `abc` 固定样本，可切换算法、看提示、展示已知摘要和比对；它不是 SwiftUI 实现或真实文件计算性能证据。浏览器视觉复核因本地 URL 策略受限，不能记为通过。

### 算法选择时的小提示

| 选项 | 选择器下方提示 |
| --- | --- |
| SHA-256 | 推荐用于一般文件校验。校验值不是加密，也不能单独证明文件来源可信。 |
| SHA-512 | 使用 SHA-2 系列算法，输出 128 个十六进制字符；适合需要 SHA-512 校验值的场景。 |
| SHA-1 | SHA-1 已不被认为具备密码学安全性，仅建议兼容旧校验值时使用。一般文件校验请选择 SHA-256。 |
| MD5 | MD5 已不被认为具备密码学安全性，仅建议兼容旧校验值时使用。一般文件校验请选择 SHA-256。 |
| 全部四种算法 | 包含 MD5 / SHA-1，仅建议用于兼容性校验；判断文件完整性优先使用 SHA-256 或 SHA-512。 |

MD5 / SHA-1 的选项带“兼容旧系统”标注，选中后显示浅琥珀色说明及信息图标；正文保持简短常驻，不用危险操作式弹窗，不要求用户二次确认，也不禁止选择。提示可链接到 [Apple Insecure 文档](https://developer.apple.com/documentation/cryptokit/insecure)。原生下拉框的单选、清晰标签和有用默认值参考 [Apple Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)。

产品统一使用“校验算法”“校验值”“计算”，不使用“加密输出”：哈希不能解密还原文件，选择算法也不会加密或修改原文件。

“拷贝全部”固定按 `MD5: <值>` 等四行输出，LF 分隔、无尾随换行；不暗带路径。单项仅拷贝摘要，写入失败要反馈。

### 数据与执行方案

- 规划模块：Core 中的 `FileInfoPolicy` / `FileDigestService` 负责支持规则、摘要格式、比对和流式计算；App 中的 `FileInfoController` / `FileInfoView` 负责窗口、授权、进度和取消；Finder 仅捕获目标并交付。名称为拟定，不代表文件已存在。
- 复用私有一次性票据，保留现有 60 秒有效期及 1 MiB 载荷上限。显式点击后异步捕获资源／父目录身份；主 App 授权后再次核对当前开关、范围、真实父目录和目标身份。无法捕获身份则报错，不用授权后碰巧出现的新对象替代。
- 内容从同一已验证句柄读取，每块只更新冻结选项中的算法，选“全部”才同时更新四个算法；初始块大小采用已有 1 MiB 经验值，性能探针后调整。默认一次只处理一个资源，进度更新节流，主线程只处理 UI。
- 在协调回调中核对实际 URL，避免路径被替换；使用不跟随末端符号链接的打开及句柄身份验证。开始、结束比较身份、字节数、修改／属性变更时间，结合可用版本标识；发现变化即废弃全部摘要，提示“文件已变化，请重新计算”。
- 上述检查不是所有外部写入下的原子快照保证。结果注明对应本次读取，不宣称持续实时有效；重新聚焦可做一次轻量变更检查，禁止后台监控。跨读取的非合作并发写入属于需明确记录的限制。
- 计算只覆盖文件数据流字节，不包含文件名、路径、扩展属性、资源叉或 Finder 元数据；空文件也有合法的四种摘要。任何无法完整读完的资源都不产生“成功”结果。
- 第一版按可读性和实际能力处理本地可用的普通文件，不新建“必须证明非 provider”的分类关口。已知未下载的云占位项提示先在 Finder 下载；不主动调用下载 API。普通读取可能由存储提供方触发物化／联网，不能承诺对所有 provider 零隐式下载。P0 验证已知占位状态可避免的路径，未知或读取失败如实反馈。
- 沿用授权边界：读摘要不请求写权限或 Full Disk Access，不扩大 Finder 观察范围；复用已有有效书签，新增授权精确到资源或必要父目录并以只读为原则。本任务不新增独立持久授权数据库。
- 与现有文件操作协调器互斥，防止 FileMint 自身在计算中移动／删除同一资源。计算中忙碌提示并聚焦现有面板，不将新请求长期排队。完成后信息面板可以保留，但释放操作占用；再次计算重新验证。退出／更新重启先取消并等待读取清理，不因空闲结果窗口永久阻塞。
- 不保存摘要历史，不记录文件内容／完整路径日志，不上传数据；用户明确拷贝或粘贴是剪贴板访问的唯一触发点。

建议性能验收：本地 SSD 的 1 GiB / 10 GiB 隔离文件，记录设备、算法吞吐、峰值额外内存、UI 响应和取消延迟；额外内存不随文件大小线性增长，目标 < 64 MiB，取消后本地读循环目标 500 ms 内响应。权限提示、系统协调或网络 I/O 等待不作硬时限承诺，显示等待并允许请求取消。性能数字是待验证目标，非既有测量。

测试矩阵还需覆盖：初始 SHA-256 且零内容读取、五种选择、MD5／SHA-1 提示、切换后旧结果失效、计算中禁用切换、全部模式比对约束、只读文件可读、无读取权、非 ASCII 名称、零字节、稀疏文件逻辑字节、断开卷、同路径对象替换、读取中截断／增长／改写、混合或过量输入、链接指向范围外、剪贴板失败、与移动／删除并发、应用退出及更新重启。未来实现按 HARNESS 跑 `make verify`、未签名 App / Finder 构建及适用原生场景；本轮不运行这些产品检查。
