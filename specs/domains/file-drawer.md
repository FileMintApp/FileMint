# File drawer

## Places and folder authorization

Enabling and opening the drawer presents Downloads, Documents, Desktop, Applications, Home, Pictures, Music, Movies, Public, Utilities, Library and Volumes as direct destinations. Use the actual user's home and the system application locations. Rendering a place requires no enumeration or authorization. A click or its keyboard shortcut enters the directory itself, including from a descendant or a filtered listing. At the browsing root, Parent Folder can open its parent through a separate explicit access check. The filesystem root has no parent.

Reuse a valid covering saved folder grant. Otherwise offer the native picker for the exact requested place or parent, remember consent in File Access and preserve the current listing on cancellation or a different selection. Neither enablement nor first use requests the disk root. The optional **Full Disk Access / 完全磁盘访问** row opens the native directory picker at the disk root when the user selects Authorize Root. Accept only that root and save its read/write App Sandbox grant in File Access. Explain the grant's scope and macOS restrictions. The drawer uses the folder picker for this flow and leaves system privacy settings entirely to the user. The saved grant is independent of the drawer's chosen display location and Finder scope.

The optional **Default Drawer Location / 默认抽屉激活位置** saves the chosen display path. The picker releases its temporary access after selection. Location preferences do not create or delete saved grants. Preserve prior saved defaults and directory grants across upgrades. If the default folder lacks a usable grant, the drawer offers an explicit authorization action for that exact folder.

**Remember Last Location / 记住上次位置** defaults on for new and existing settings. Each fresh opening first tries the last displayed directory when enabled. Revalidate its directory identities and current authority. If it cannot be restored, try the default folder, then show the location chooser when no default is available. Persist the last directory snapshot locally across app launches and keep it out of settings export. A snapshot carries no permission. A session-only picker grant can be reused within that app session. Turn the switch off to clear the saved position and use the default on every fresh opening. Refocusing an already open drawer preserves its directory and interactions.

Navigation resolves saved grants and favorite identities on the directory worker. Only a still-current navigation can present its missing-grant picker. Entering an authorized breadcrumb validates its captured directory chain, including the current folder; a same-name replacement cannot redirect the action. Re-entering the current folder clears its filter and keeps its history position.

The Locations button and Command-L expand or collapse the sidebar at every drawer width. Direct location shortcuts remain available while it is collapsed. Command-Shift-L or clicking the Locations heading opens a native Go to Location menu containing all standard places and saved folders. The menu supports arrow-key navigation, Return and Escape without requiring keyboard access to sidebar buttons. Its choices use the same folder grants as sidebar rows. Display standard and saved folders together with the Add Folder command. The locations area has no search interface.

Removing a saved grant retires the browsing history, transfers, previews and restoration records that depend on it after the current interaction finishes. Independently chosen locations retain their own authority. Changing the default leaves a browsable open location in place. Gate new access on the current grant after importing settings or reopening the drawer.

## Drawer behavior

- The main app owns one optional accessory file drawer. Enable it in Extensions → File Drawer to expose a separate command in the status menu and File menu. New and migrated settings default off. Quick Search remains an independent command.
- An enabled drawer offers Control-Option-D by default. Reserve the Quick Search suggested and saved combinations for Quick Search even while it is disabled. On import, startup or a Quick Search reassignment, the drawer yields a conflicting key and reports its inactive state. An explicitly saved, nonconflicting drawer combination remains authoritative when the suggested default changes. Its settings let the user disable the global shortcut independently, record a combination or restore the default. Register only while the module and shortcut are enabled. Handle collisions with Quick Search, system shortcuts and other apps, preserve working registrations on failed edits, and report an unavailable combination with a retry. The key opens the drawer, focuses a visible background drawer or closes a focused one. Sheets and active file interactions retain priority.
- The absolute path occupies one dedicated full-width row above the sidebar and files. Its slash-separated components scroll horizontally and the copy button remains reachable at narrow widths. Click a component to enter that folder and clear the filter. A secondary click or the component's accessibility action offers browsing of direct children on demand. Choosing a file navigates to its parent and selects that exact file. Above-root path components need a matching grant to browse. Menu dismissal, a changed directory or stale identity cannot activate an old result.
- Present on the pointer's display, docked left or right (initially right). Pinning keeps the drawer up when switching apps.
- Start at the authorized root, an explicitly chosen folder or a saved favorite folder. Hold valid sandbox access while the directory, a pending operation or its preview is in use. Browse one explicitly visited directory at a time, off the main thread. Never discover a directory tree in the background or silently widen Finder scope. Show navigation history, parent/breadcrumb, refresh and single or multiple selection. Obsolete navigation and preview completions cannot replace the current selection.
- Open or locate selected items, copy paths and add favorites explicitly. New File uses FileMint's existing template draft at the current directory and writes only on Create. Provide new folder, rename, copy/move to a chosen destination (including paste and dragging onto a folder), system Trash with confirmation and session restoration when supported. Use the captured objects and independently authorized destination. Reject invalid names, replacements, out-of-root symlinks, collisions and moves into descendants. Same-folder copies receive an available duplicate name. Moving across volumes is rejected before changing the selection and directs the user to copy to the other volume. Never overwrite or fall back to permanent deletion. Report partial success and refresh affected listings.
- Automatic preview defaults off. Space or an explicit Preview action requests native Quick Look for one available regular file. When enabled, debounce selection and auto-preview only known sizes up to 50,000,000 bytes. Use Quick Look directly for ordinary text, images, PDF and audiovisual media. For other types, automatic preview waits for a native content thumbnail. Manual preview can use installed preview-only providers. Bigger or unknown sizes require a manual request. Silently skip unavailable previews, including offline files, links, packages and files that changed before Quick Look could open them. Show no preview eligibility messages or empty preview strip. Close old previews and release access on deselection, navigation, disable or dismissal.
- Use bilingual FileMint controls and a quiet mint selection on adaptive surfaces. Preview generation and file actions are user-initiated or governed by the explicit auto-preview switch. No background filesystem indexing, clipboard observation, path logging or new filesystem entitlements.

## Window and interaction

- Command-K or the selected-items Actions button opens a compact action palette over the lower trailing corner of the drawer. Keep the files visible behind it. Show the selected filename or item count, actions available to that selection, their saved hint visibility, and a focused action search field. Up/Down and Return select and run a match. Escape, a second Command-K or clicking outside the palette cancels it and restores file-list focus. Text composition, rename, other menus, owning sheets and drafts keep priority.
- Use the existing drawer file operations and confirmations. Opening the palette captures the selection and directory identities. Navigation, refresh, a new selection, or dismissal invalidates it. Before executing a command, verify its captured entries off the UI thread and recheck that its session and selection are still current. A changed file leaves the replacement untouched and refreshes the listing.
- Open With works for files of any extension, folders, packages and mixed selections. The chooser combines configured apps, common system suggestions and an explicit other-app picker. Dispatch under the existing drawer grant according to [Open with App](open-with.md#drawer-open-with).

- Rename edits the captured item's visible filename in place in all three layouts. Return and the Rename action focus the same field. Initially select the basename of a file and the full name of a folder. Return commits, Escape cancels, and moving to a different item or directory discards an uncommitted edit. Keep invalid or occupied names editable. If the source identity changed, end the obsolete edit, clear that selection, refresh the directory and explain the change. An unpinned drawer stays open during editing and the exclusive write.
- Center the drawer vertically within the current display's usable frame in all sizing modes. Width and height have independent fit-to-display switches and editable minimum and maximum limits. Width limits initially span 320–640 pt, adjustable within 240–2,000 pt. Height limits initially span 480–1,100 pt, adjustable within 480–4,320 pt. Older preferences with a taller saved height receive an upper limit that accommodates it. Automatic sizing uses 520 pt width at 1,440 pt and 72% of available display height. Apply the saved limits in both automatic and fixed modes, then fit to the display without overwriting the user's preferences. An explicitly edited preferred size switches that dimension to fixed mode. Editing only bounds preserves its current mode and brings its previous preferred size into the new range. Keep invalid edits visible and explain the allowed range. Valid edits apply on Return, ending editing, or Apply, update a visible drawer, and survive reopening. The inner edge still supports dragging to set a fixed width.
- Fade the drawer in and out with a short 8 pt shift at its chosen edge, independent of drawer width. Reverse an in-progress transition from its current appearance. Use a system-composited transition on the display's refresh cycle, clipped to the drawer's own display. Honor Reduce Motion immediately and recalculate placement after screen reconfiguration or disconnection.
- Use an adaptive AppKit floating-panel material and the system window background for reduced transparency. Background transparency starts at 30% and never dims text or controls.
- New File hands focus to the native draft and preserves the originating drawer through edit, creation and cancellation. Name sheets, destination pickers, confirmations, menus, dragging and in-flight writes also retain their owning window while unpinned. Explicit disable still tears down the drawer.

## Open With application picker

Every nonempty selection offers Open With in its action palette, including folders, packages, mixed selections and files with an unknown type. Choosing Open With keeps the captured selection and replaces the action rows with application choices. Support name filtering, arrow keys and Return. Back or Escape returns to actions. Other Application opens a single-application picker; cancelling returns to the application list. A changed selection, a newer picker or dismissal invalidates previous results and pending choices. Selecting an application requests a one-time open of the complete selection.

## Search within the open folder

- Search the captured names of visible direct children, including their extensions. All space-separated terms must occur, in any order. Match case, accents and character width insensitively; keep the chosen folders-first sort order. An empty search restores the listing.
- Prepare search names and sort the directory snapshot off the main thread. Reuse that snapshot between keystrokes without filesystem access or a persistent index. Cancel obsolete searches and discard completions after edits, navigation or dismissal. Selection and file actions must refer to visible, current results. Return in the search field selects the first result for that query.

## Sort order and views

Keep folders first in both directions. Offer natural name order, file kind (grouped by filename extension), size and modification date. A newly chosen name or kind sort starts ascending, size or date descending. Equal values use natural ascending filename order with a deterministic spelling tie-break. Remember the last field and direction.

Offer icon, list and compact list views in a named view picker. The ordinary list shows metadata where space allows. Compact list rows prioritize filenames and use less vertical space. Preserve the file selection, search and folder when changing views. Remember the view and sort preferences. Older settings start in list view sorted by ascending name.

## Local keyboard controls

With keyboard focus on the file collection, plain Down and Up select the next and previous visible items in sort order in every layout. From an empty selection Down starts at the first item and Up at the last. Keep the selection visible and stop at the ends. Right enters one selected browsable folder. Left goes to the parent through the existing folder access flow and selects the departed child if the parent listing still contains that directory identity. Text editing, overlays, sheets and modifier-assisted selection keep their native keys.

While the drawer owns keyboard focus, Command-K opens or closes actions for its current file selection. Keep the application's Favorite Locations shortcut available in other windows. A selected browsable folder offers FileMint's template creation draft targeting that folder. Keep the drawer at its original location and require Create to write.

In the action panel, Return runs the highlighted row. Other visible key hints invoke their corresponding actions directly. Preserve native text editing in the action search, including copy, paste and composing text.

The drawer handles Command-W to close, Command-Shift-P to pin, Command-N to create a file and Command-Shift-N to create a folder while it is the key window, including when folder search has focus. Command-Option-1 through 9 open the first nine standard places. Command-Up opens the parent. Name editing, IME composition, menus, sheets and drafts retain priority. File selection, rename, preview, copy/move, copy paths, reveal, favorites, Trash and restoration remain local to the file list. Command-F focuses folder search. Return from search selects a result and moves focus to the file list.

Show shortcut hints by default, including on migration. A saved switch in drawer settings controls contextual key hints and the compact keyboard guide. Hiding hints keeps the same keyboard behavior.

## Sidebar and readability

Keep standard places and user-added folders accessible in a scrolling leading sidebar, including on first open. Show named rows whenever it is expanded. At narrow widths the expanded location list uses the content width. Choosing a location returns to the files. Collapsing Locations gives the file browser the full content width. The Add Folder picker writes to the existing Favorite Locations catalog. Display its saved folders across sessions and keep favorite files in their existing surfaces. Resolve a location only when activated. Use regular-size native controls, legible navigation, filename and feedback text, and larger icon targets.
