# 隐私，应该不需要猜

FileMint 的文件创建、文档模板与图片处理在本机完成。它不要求账号，也不收集使用分析数据。

## QA 功能预览的数据边界

以下功能仍处于 QA 阶段，当前稳定版尚未提供：

- **常用文件（夹）**只保存你主动添加的本地项目书签及显示信息；不扫描目录、不读取文件内容。
- **移除隐私元数据**只处理你明确选择的本地图片，生成经读取校验的新副本；不上传图片，原图保持不变。
- **Finder 隐藏项目切换**由用户明确点按触发，依赖 macOS 辅助功能授权；不保存或推断 Finder 的隐藏项目状态。

这些说明只描述 QA 预览的设计，不代表这些功能已进入稳定安装包。

## 不会收集什么

- 文件名、路径和内容不会上传。
- 不扫描目录，不给文件打标，也不在后台枚举文件。
- 不监控剪贴板。粘贴文本或选择“图片粘贴为文件”时才读取对应内容；拷贝名称、路径、编辑器文本或 OCR 结果都由你明确触发。图片预览不会自动保存文件。
- 导入 Word / Excel 模板时，只读取你选择的文档，并在应用私有目录保存独立副本。不会上传模板，也不追踪原文件后续的变化。
- “使用 App 打开”只把所选项目交给你配置的本地应用，不改变默认文件关联。被打开应用的后续行为由该应用负责。
- 文件（夹）工具只处理你在已授权范围内明确选中的项目。它不会读取文件内容、扫描目录或上传名称、路径和待移动状态。“彻底删除”只在你点按后处理捕获的项目，不记录路径或内容；“隔空投送”只把所选文件 URL 交给 macOS 系统分享服务，由系统处理接收设备选择。
- 资源工具只处理你明确选择的本地图片。转换、压缩、缩放、拼接和 OCR 都在本机完成；原图保留，不上传图片、文字结果或处理历史。

## 什么时候会联网

主应用通过 GitHub 检查和获取更新。自动检查默认开启，可在“通用”中关闭；仅在 FileMint 运行时进行，每 7 天最多一次，只获取版本信息。你也可以手动检查。下载、安装和重启需要你选择“更新并重启”，不会后台自动下载。Finder 扩展不需要网络。
