# 隐私，应该不需要猜

FileMint 的文件创建、文档模板、批量重命名、校验值计算与图片处理在本机完成。它不要求账号，也不收集使用分析数据。

## 由你主动触发的数据访问

- **从剪贴板新建**只在你明确选择该操作时读取一次纯文本，不监控剪贴板，也不会自动保存。
- **在当前目录打开 App**只把 Finder 捕获的已授权目录交给你配置的本地应用；终端的后续行为由终端负责。

- **常用文件（夹）**只保存你主动添加的本地项目书签及显示信息；不扫描目录、不读取文件内容。
- **移除隐私元数据**只处理你明确选择的本地图片，生成经读取校验的新副本；不上传图片，原图保持不变。
- **Finder 隐藏项目切换**由用户明确点按触发，依赖 macOS 辅助功能授权；不保存或推断 Finder 的隐藏项目状态。
- **批量重命名**只处理你主动选择并确认的文件或文件夹，不读取文件内容或遍历子目录。恢复和最近一次撤销所需的操作记录保存在本机，不上传。
- **文件信息与校验值**打开时只读取所选文件的元数据；明确点击“计算”后才读取文件内容。结果仅保留在当前窗口，不保存校验历史；拷贝和预期值比对由你主动触发。
- **拷贝文件内容**只在明确选择 Finder 操作后读取所选文本文件。源文件与解码文本均限制在 8 MiB；先完整校验再写入剪贴板，不上传、记录或缓存内容，失败及取消不发布部分结果。
- **快捷搜索**仅在本机匹配已有操作、模板、常用文件和设置，不扫描目录。查询与选择仅在本次应用会话的内存中保留；可选全局快捷键只向 macOS 注册所选组合，不记录其他按键，也不需要输入监控或辅助功能权限。

## 不会收集什么

- 文件名、路径和内容不会上传。
- 不扫描目录，不给文件打标，也不在后台枚举文件。
- 不监控剪贴板。粘贴文本、选择“从剪贴板新建”或“图片粘贴为文件”时才读取对应内容；拷贝名称、路径、编辑器文本或 OCR 结果都由你明确触发。图片预览不会自动保存文件。
- 导入 Word / Excel 模板时，只读取你选择的文档，并在应用私有目录保存独立副本。不会上传模板，也不追踪原文件后续的变化。
- “使用 App 打开”只把所选项目或当前目录交给你配置的本地应用，不改变默认文件关联。被打开应用的后续行为由该应用负责。
- 文件（夹）工具只处理你在已授权范围内明确选中的项目，不扫描目录或上传名称、路径和操作状态。拷贝名称、路径及批量重命名不读取文件内容；校验值计算按上文所述读取所选文件。“彻底删除”只在你点按后处理捕获的项目，不记录路径或内容；“隔空投送”只把所选文件 URL 交给 macOS 系统分享服务，由系统处理接收设备选择。
- 资源工具只处理你明确选择的本地图片。转换、压缩、缩放、拼接和 OCR 都在本机完成；原图保留，不上传图片、文字结果或处理历史。

## 什么时候会联网

主应用通过 GitHub 检查和获取更新。自动检查默认开启，可在“通用”中关闭；仅在 FileMint 运行时进行，每 7 天最多一次，只获取版本信息。你也可以手动检查。下载、安装和重启需要你选择“更新并重启”，不会后台自动下载。Finder 扩展不需要网络。

官网在页面打开时向 GitHub 公开 API 请求最新正式版信息，用于显示版本和下载链接。此请求不读取你的本地文件，也不发送账号凭据。

校验值计算不把文件交给远程处理服务。已知未下载的云文件需先在 Finder 下载；其他文件的普通读取仍可能触发系统或云盘服务取回内容，不能据此保证所有存储位置都完全离线。

完整条款见 [GitHub 上的隐私说明](https://github.com/FileMintApp/FileMint/blob/main/PRIVACY.md)。
