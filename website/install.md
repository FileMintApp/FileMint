# 安装 FileMint

已发布的 0.5.10 DMG 支持 macOS 13+、Apple 芯片和 Intel Mac。后续正式版仅支持 **macOS 13+ 的 M 系列 Mac**；旧版安装包的兼容范围不变。

0.5.9 及后续正式版安装包使用 Developer ID 签名，已通过 Apple 公证并附加公证票据。

## 首次安装

1. 从 [GitHub Releases](https://github.com/FileMintApp/FileMint/releases/latest) 下载最新 DMG。
2. 打开 DMG，把 FileMint 拖入“应用程序”。
3. 从“应用程序”启动 FileMint，按应用内提示启用 Finder 扩展并授权常用文件夹。
4. 回到 Finder，在桌面或已授权文件夹的空白处右键，选择“新建文件”。
5. 如需文件（夹）工具，打开“设置 → 扩展功能 → 文件（夹）工具”，再开启总开关和需要的子项，并为每项选择一级或二级菜单位置。

Finder 扩展与文件夹授权是独立的系统能力。FileMint 会引导你打开对应的系统设置，但不会静默修改系统权限。

安装完成后，可按[使用指南](./guide)逐步创建第一份文件、配置模板和启用可选工具。

## 从模板创建文件

在“模板与类型”中启用和排序常用格式，也可以新建文本模板，为同一后缀保存不同的默认文件名和初始内容，并选择默认模板。

点击“导入文档模板”选择一个 `.docx` 或 `.xlsx`。FileMint 会在本地保存独立模板副本；以后从 Finder 或创建面板选择该模板，就能生成保留格式与内容的新文档。同名时自动编号，不覆盖已有文档。自定义文本后缀不会转换为 Word、Excel 或其他二进制格式。

## 将剪贴板图片保存为文件

拷贝一张截图或位图，在 FileMint 或 Finder 的“新建文件”菜单中选择“图片粘贴为文件”。确认预览、文件名和保存位置后，点击“创建”保存为 PNG。取消不会生成文件；同名自动编号。

## 使用 App 打开

在“扩展功能 → 使用 App 打开”中添加常用应用，并为每项选择一级菜单或二级菜单。然后在已授权的 Finder 文件夹中选中文件或文件夹，用对应入口打开。新安装时应用列表为空；此功能不会改变系统默认打开方式，支持的文件类型由所选 App 决定。

## 开启文件（夹）工具

文件（夹）工具默认关闭。启用后，请在已授权范围内选中一个或多个本地文件或文件夹。每项已启用工具可按设置直接显示在一级菜单，或收进“文件（夹）工具”子菜单；新建文件菜单保持不变。

- “拷贝文件（夹）名称”保留后缀；“拷贝文件（夹）路径”写入完整本地路径。多选时每项各占一行。
- “移动文件（夹）”先记住源项目，不会立即移动；到目标文件夹的空白处右键，选择“将所选项目移到此处”才会执行。这个目标操作也能单独选择菜单层级。
- 同名项目不会覆盖或合并。若有项目未完成，解决问题后可再次从目标位置尝试；再次选择源项目会替换上一批待移动项目。
- “彻底删除”默认二次确认并绕过废纸篓；可在设置中明确改为“直接静默删除”。静默模式不跳过文件夹授权，删除符号链接时只删除链接本身。
- “隔空投送”默认关闭。开启后会拉起 macOS 原生隔空投送界面，由你选择接收设备；不会自动发送或改用其他分享方式。
- “发送替身到桌面”创建指向原项目的 Finder 原生替身，不复制或移动原文件。同名时自动编号，该工具默认关闭。
- 菜单只在当前选中项目全部位于已授权范围内时显示，不会扫描目录或监听剪贴板。

## 使用资源工具

打开“扩展功能 → 资源工具 → 使用工具”，就可以在主应用中选择图片，无需启用 Finder 菜单。若想从 Finder 右键开始，在“Finder 菜单设置”中开启默认关闭的资源工具模块，再启用需要的子项。

- 支持格式转换、压缩、调整尺寸、生成 ICNS/ICO/PNG 图标、拼接图片和 OCR 提取文字。
- 处理面板先显示预览和输出位置；原图始终保留，输出是同目录副本或你明确选择的目录。
- 图片和 OCR 结果只在本机处理，不上传，也不保留处理历史。

## 外观与语言

在“通用 → 外观”中选择跟随系统、浅色或深色主题，以及中文、英文或跟随系统的界面语言。主题即时应用到 FileMint 的窗口，不改变 macOS 的系统外观。

## 后续更新

自动检查更新默认开启，可在“通用”中关闭。FileMint 运行时每 7 天最多检查一次，只获取版本信息；下载和安装仍由你决定。关闭后仍可手动检查。

安装 0.5.9 后，可选择“关于 → 检查更新 → 更新并重启”获取后续版本。
请先完成文件创建或编辑；macOS 可能要求管理员授权。

从 0.5.7/0.5.8 升级时，请手动安装 0.5.9 或更新版本一次。旧版安装器的签名权限问题无法自行修正。下载并打开 DMG 后：

1. 退出 FileMint。
2. 将新版拖入“应用程序”替换旧版。
3. 推出 FileMint 安装磁盘，再从“应用程序”重新打开。

完整的安装限制、更新说明和发布来源记录，请阅读 [GitHub 安装指引](https://github.com/FileMintApp/FileMint/blob/main/docs/INSTALL.md)。
