# FileMint 使用指南

跟着下面的步骤，先在 Finder 创建一份文件，再按需要开启其他功能。尚未安装？先看[安装指引](./install)。截图中的文件、应用和开关仅用于演示，你的初始设置可能不同。

## 先完成首次设置

1. 从“应用程序”打开 FileMint。如果“通用”页面提示 Finder 扩展未启用，点击“打开扩展设置”，在 macOS 中开启 FileMint，然后回到应用查看状态。
2. 打开“Finder 与文件夹”，确认要使用的文件夹在菜单显示范围内；对显示“需首次选择此文件夹以授权”的位置，点击“授权访问…”并在系统选择器中选择该文件夹。
3. 切回 Finder，在**桌面或已配置文件夹的空白处**右键，找到“新建文件”。

在 macOS 15 及更新版本中，扩展开关通常位于“系统设置 → 通用 → 登录项与扩展 → Finder”；较旧系统在“隐私与安全性 → 扩展”。Finder 扩展和文件夹访问是两项独立设置。即使开启“完全磁盘访问权限”，仍需按提示选择工作文件夹，让 FileMint 保存文件夹授权。

不打算使用 Finder 右键菜单？主应用侧栏的“新建文件…”和“资源工具 → 使用工具”仍可直接使用。

## 在当前位置创建文件

### 一步创建常用格式

在 Finder 的桌面或文件夹空白处右键，打开“新建文件”，再选“文本 (.txt)”“Markdown (.md)”等已启用的格式。文件会立即创建在**刚才右键的位置**；如果同名文件已存在，默认在名称后自动编号。

![Finder 文件夹空白处的右键菜单，展开“新建文件”后显示“新建文件…”及已启用的格式](/images/finder-folder-context-menu-zh.png)

<p class="guide-caption">图示为已启用多个格式的示例；实际菜单由“模板与类型”中的设置决定。</p>

### 自己填写名称与内容

需要指定文件名、保存位置或第一段内容时，选择“新建文件 → 新建文件…”。在面板里输入完整文件名，例如 `project-kickoff.md`，确认格式和位置，填写可选的初始内容，最后点击“创建”。点击“取消”不会写入文件。

![新建文件面板，显示文件名、格式、保存位置、初始内容以及取消和创建按钮](/images/create-panel-zh.jpg)

<p class="guide-caption">文件名、格式、保存位置和初始内容都能在创建前确认。</p>

完整文件名会决定后缀；选择另一种格式时，面板会同步更新文件名。初始内容按输入的原文保存。自定义后缀创建的是文本文件，不会把文本转换成 Word、Excel 或图片。

<strong>键盘操作：</strong>在面板内按 Tab / Shift-Tab 切换控件，按 ⌘↩ 创建，按 Esc 取消；在内容编辑框中按 Return 会换行。粘贴按钮只在你点击时读取剪贴板文本。

## 保存常用模板

打开“模板与类型”，勾选常用格式并调整顺序。点击“新建文本模板…”，填写模板名称、默认文件名和初始内容；同一种后缀可以保存多个模板，并选择默认模板。之后可从 Finder 菜单或创建面板选择它。

![模板与类型页面，显示新建文本模板、导入文档模板和格式启用列表](/images/file-types-zh.jpg)

<p class="guide-caption">这里决定哪些格式进入 Finder 的快捷创建菜单。</p>

要复用现有 Word 或 Excel 文档，点击“导入文档模板…”，选择 `.docx` 或 `.xlsx`。FileMint 在本地保存独立副本；以后选择该模板会生成保留原文档格式与内容的新文件，不修改原文档。同名输出会自动编号。

## 把剪贴板图片变成 PNG

1. 先复制一张截图或位图。
2. 在 FileMint 侧栏，或 Finder 的“新建文件”菜单中选择“图片粘贴为文件…”。
3. 核对预览、文件名和保存位置，再点击“创建”。

图片只在你选择这项操作时读取；取消不会生成文件。这个入口保存为 PNG，且会为同名文件自动编号。

## 用自己的 App 打开所选项目

打开“扩展功能 → 使用 App 打开”，点击添加应用，选择本机 App，并决定它显示在 Finder 一级菜单还是“使用 App 打开”子菜单。然后在已配置的 Finder 文件夹中选中文件或文件夹，右键选择对应 App。

![使用 App 打开设置，显示已添加应用及其菜单位置](/images/open-with-zh.jpg)

<p class="guide-caption">图中应用是示例配置；新安装时列表为空。支持哪些文件由所选 App 决定。</p>

这个功能不会更改 macOS 的默认打开方式。若菜单里没有某个 App，请先确认已添加、App 仍在原位置，且所选项目位于菜单显示范围内。

## 按需开启文件（夹）工具

打开“扩展功能 → 文件（夹）工具”，先开启总开关，再开启需要的子项。每项可放在 Finder 一级菜单或“文件（夹）工具”子菜单；总开关初始关闭。

![文件（夹）工具设置，显示各项功能开关及菜单位置](/images/file-tools-zh.jpg)

<p class="guide-caption">截图为开启工具后的示例。请按实际需要选择，尤其留意“彻底删除”的设置。</p>

- <strong>拷贝名称 / 路径：</strong>选中一个或多个项目后右键执行；多选时每个项目各占一行。
- <strong>移动：</strong>先选中源项目并执行“移动文件（夹）”；随后到目标文件夹的<strong>空白处</strong>右键，选择“将所选项目移到此处”。第一步只记录待移动项目；已有同名项目不会被覆盖或合并。
- <strong>彻底删除：</strong>绕过废纸篓，默认要求二次确认，删除后无法撤销。只在明确需要时开启。
- <strong>隔空投送 / 发送替身到桌面：</strong>前者打开 macOS 的隔空投送界面，由你选择接收设备；后者创建指向原项目的 Finder 替身，不移动原文件。

## 处理图片与提取文字

在主应用打开“扩展功能 → 资源工具 → 使用工具”，选择本地图片即可开始，无需启用 Finder 菜单。若想从 Finder 右键启动，在同页“Finder 菜单设置”中开启资源工具总开关和需要的动作，再选中图片右键操作；这个总开关默认关闭。

![资源工具页面，显示格式转换、压缩、调整尺寸、图标、拼接和文字提取六项操作](/images/resource-tools-zh.jpg)

<p class="guide-caption">“使用工具”用于主应用内操作；Finder 菜单可单独开启。</p>

可转换 JPEG、PNG、HEIC、TIFF，压缩或调整尺寸，生成图标，拼接至少两张图片，或用 OCR 提取文字。处理面板会先显示预览和输出位置；选好参数后再执行。原图保持不变，结果保存为新文件。OCR 结果可以编辑，再由你选择拷贝或保存为 TXT。

## 调整外观与更新

“通用 → 外观”可选择跟随系统、浅色或深色主题，以及中文、英文或跟随系统的语言。“关于”提供手动检查更新；自动检查更新也可在“通用”中关闭。更新涉及的安装步骤见[安装指引](./install#后续更新)。

## 遇到问题时

<strong>Finder 中没有“新建文件”：</strong>先在 FileMint 查看 Finder 扩展状态，确认系统扩展开关已开启；再检查右键的位置是否在菜单显示范围内。授权变化后若菜单仍未刷新，可重新启动 Finder。此时也可从主应用侧栏使用“新建文件…”。

<strong>能看到菜单，但保存时要求授权：</strong>按 FileMint 提示，在系统文件夹选择器中选择当前工作文件夹。“完全磁盘访问权限”与 FileMint 保存的文件夹授权不同；设置页仍显示权限说明，并不表示系统开关一定关闭。

<strong>找不到某个工具：</strong>先确认是在正确位置右键：创建文件要点文件夹空白处，文件（夹）工具和“使用 App 打开”要先选项目，资源工具要先选受支持的图片。然后检查该模块总开关、子项开关和一级/二级菜单位置。

还有问题？可到 [GitHub Issues](https://github.com/FileMintApp/FileMint/issues) 描述 macOS 版本、FileMint 版本、操作入口和看到的提示。请勿公开私人文件内容或完整路径。
